# Как работает TrackFix

## Общее описание

TrackFix — это приложение для исправления GPS-координат треков. Оно использует эталонный маршрут (GPX или FIT) для восстановления пропущенных или искажённых координат в исходном треке.

## Алгоритм работы

1. **Чтение файлов**:
   - Исходный трек: содержит GPS-координаты и данные датчиков (время, дистанция, скорость)
   - Эталонный маршрут: правильный путь для этой тренировки

2. **Анализ проблемных участков**:
   - Определяются точки, которые сильно отклонились от эталона
   - Используются алгоритмы выравнивания для определения соответствия между треками

3. **Исправление координат**:
   - Проблемные точки заменяются на координаты из эталонного маршрута
   - Все остальные данные (время, дистанция, скорость) сохраняются из исходного файла

## Новый режим "Маршрут восстановлен по эталону" (v1.7.6)

В версии 1.7.6 добавлена опция "Маршрут восстановлен по эталону". При включении этой функции:

- Используются координаты из эталона (по дистанции исходника)
- Все показатели (время, дистанция, скорость) берутся из исходного файла
- Позволяет исправлять треки с нестабильным GPS-сигналом, сохраняя данные датчиков

## Специфические алгоритмы

### Исправление плавных отклонений (Smooth Deviations)

- При покрытии треком эталона в диапазоне 0.8–1.2 длины автоматически исправляются плавные отклонения
- Это позволяет устранить мелкие неточности без риска искажения данных

### Ремонт на повторяющихся кругах

- При обнаружении повторяющихся участков (например, стадионный круг) используется алгоритм выравнивания
- Учитываются глобальные параметры дистанции и времени для точного соответствия

## Технические детали

### Координаты и расстояния

- Используются координаты из эталонного маршрута
- Расстояние рассчитывается по формуле Гаверсина (Haversine)
- Для вычислений применяется алгоритм проекции точек на кривую

### Обработка ошибок

- При отсутствии GPS-координат в исходном треке применяется восстановление по эталону
- Проверяется корректность времени и дистанции
- Все предупреждения выводятся пользователю с описанием проблемы

## Особенности реализации

- **Нельзя добавлять/удалять точки** — сохраняется оригинальное количество точек
- **Не изменяется порядок точек** — сохраняется последовательность
- **Время и датчики остаются без изменений** — сохраняются все данные датчиков
- **Существующая высота не меняется** — сохраняется только при необходимости

## Сравнение с другими приложениями

- Отличается от других решений тем, что сохраняет данные датчиков даже при исправлении координат
- Использует эталонный маршрут для точного восстановления данных
- Обеспечивает высокую точность в случае повторяющихся участков

## Требования к файлам

- Исходный файл: GPX или FIT с GPS-координатами и данными датчиков
- Эталонный файл: GPX или FIT, соответствующий тренировке (см. «О программе»)
