TrackFix GPS, объединение и фото — без загрузки файлов на сервер

Работает прямо в браузере

Исправляйте треки, объединяйте записи и собирайте карточки тренировок

Выберите файлы GPX или FIT. Данные не отправляются никуда: вся обработка выполняется локально на вашем устройстве.

GPX · FIT

Исправление трека

Восстановите GPS по эталонному маршруту. Время, точки и показатели датчиков сохраняются.

GPX / FIT → GPX

Объединить треки

Добавьте два или больше трека GPX или FIT. Приложение само определит порядок по времени начала.

GPX + FIT → GPX

    Данные на фото

    Наложите показатели тренировки на фотографию и сохраните готовую карточку.

    Трек + фото → PNG
    Данные на фото Можно выбрать несколько показателей
